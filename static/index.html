🔄 格式转换

选择一个或多个文件，再选目标格式。批量时只会列出所有文件都支持的目标格式。

Word / Excel / PPT 转 PDF 默认调用本机 Microsoft Office，排版与 Office 一致；Word 自动化不可用时会自动改用内置排版引擎并给出提示。扫描版 PDF 转 Word 时请选择「Word（可编辑 .docx）」。

🗜️ 文件压缩

图片与 PDF 按质量比例压缩，其它类型打包为 zip。压缩级别越高，体积越小、画质损失越明显。

预估会在后台真正压缩一次，不额外改变最终结果；也可以跳过，直接压缩。

📑 PDF 转 JPG（每张 ≤300KB）

一次选中整个文件夹，自动筛出其中的 PDF 并逐页导出 JPG。优先保证清晰度，超出 300KB 时自动降低 JPEG 质量与分辨率。

尚未选择文件。可点击上方「选择整个文件夹」一次性导入。

📷 扫描照片

上传一张手机拍摄的纸质文件照片，自动识别纸张四角、裁切、透视矫正、去阴影并增强对比度，最后输出灰度扫描 JPG（灰度能明显压掉阴影与色偏，文字更干净）。

请让纸张完整露出，且背景与纸张有明显色差；只支持一次一张图片。未识别到纸张边缘时会保留全图并只做去阴影增强。

🔗 PDF 合并与插入

按文件列表顺序处理；「指定页插入」以第一个 PDF 为主文件，其余 PDF 插入到指定位置。可在上方列表中拖拽调整顺序。

主 PDF 的页码，从 1 开始；填 0 表示插到首页之前。

尚未选择文件。至少需要两个 PDF。
